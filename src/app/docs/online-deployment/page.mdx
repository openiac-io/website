# On-Premise Platform Deployment

OpenIaC provides a unified, zero-config workflow for deploying container, virtualization, and private cloud platforms on **RHEL / Rocky Linux** hosts.

## 1. Configure Target Host IPs

Update the IP addresses of your target servers in the corresponding sample inventory under `ansible/inventories/<platform>-sample/hosts.ini`:

```ini
# Example: ansible/inventories/k8s-sample/hosts.ini
[all_nodes]
cp-01 ansible_host=192.168.56.10
worker-01 ansible_host=192.168.56.20
worker-02 ansible_host=192.168.56.21

[k8s_control_plane]
cp-01

[k8s_workers]
worker-01
worker-02
```

## 2. Run One-Command Deployment

From the root of the `openiac` repository, execute the `make` target for your desired platform:

```bash
# Deploy Standard Upstream Kubernetes (Kubeadm + Containerd + Calico)
make k8s

# Deploy Lightweight Kubernetes (SUSE Rancher K3s)
make k3s

# Deploy Cloud-Native VM Virtualization (KubeVirt + CDI + virtctl)
make kubevirt

# Deploy OpenShift / OKD (Defaults to free OKD; set openshift_edition: "ocp" for Red Hat OCP)
make openshift

# Deploy OpenStack Private Cloud (Kolla-Ansible)
make openstack
```

## What Happens Automatically?

- **Base OS Hardening & Kernel Tuning**: Disables swap, configures SELinux permissive mode, loads `overlay` and `br_netfilter` modules, and applies CRI sysctl network parameters.
- **Built-in Invisible Helpers**: Automatically provisions HAProxy for OpenShift, LVM `cinder-volumes` and Neutron dummy interfaces for OpenStack, and QEMU emulation fallback for KubeVirt when `/dev/kvm` is absent.
- **Automatic Kubeconfig & Credentials**: Configures `~/.kube/config` on control plane nodes and `/etc/kolla/admin-openrc.sh` for OpenStack immediately after installation.
